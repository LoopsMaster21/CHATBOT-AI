# **App Name**: Spinneys ChatAssist

## Core Features:

- Intelligent Chatbot: AI-powered chatbot trained on Spinneys Lebanon data (products, FAQs, etc.) to provide helpful answers. The chatbot uses a tool to determine when information available via URL and/or text should be included in its output.
- Chat History: Persistent chat history to maintain context throughout the conversation.
- Download Chat: Button to download the entire chat conversation as a .txt file.
- Voice-to-Text Input: Voice message input that converts speech to text for sending to the chatbot.
- Text-to-Speech Output: Text-to-speech functionality using Google's AI voices to audibly convey the chatbot's responses.

## Style Guidelines:

- Primary color: A vibrant yet approachable blue (#4285F4) reminiscent of helpful technology.
- Background color: A light, desaturated blue (#E3F2FD), offering a clean and calming interface.
- Accent color: An energetic yellow (#FFCA28) for interactive elements and highlights, providing a friendly feel.
- Body and headline font: 'PT Sans' (sans-serif) for clear and accessible text, readable on all devices.
- Use clean and modern icons to represent different categories and actions, improving usability.
- Clean and intuitive layout with a clear separation between user input and chatbot responses.
